# Relationship Policy & Filter

**Boundary ≠ hostility.** Bukan memutus semua orang — tapi memilih secara sadar.

## KEEP / LIMIT / RELEASE

| Nama / Situasi | Menghargai? | Jujur? | Reciprocal? | Menguras energi? | Drama berulang? | Keputusan |
|---|---|---|---|---|---|---|
| | ☐ | ☐ | ☐ | ☐ | ☐ | KEEP / LIMIT / RELEASE |
| | ☐ | ☐ | ☐ | ☐ | ☐ | KEEP / LIMIT / RELEASE |
| | ☐ | ☐ | ☐ | ☐ | ☐ | KEEP / LIMIT / RELEASE |

- **KEEP** → menghargai, jujur, bertumbuh, reciprocal, membuat hidup lebih sehat
- **LIMIT** → selalu mengambil, drama berulang, menguras energi, hanya datang ketika butuh
- **RELEASE** → berkali-kali terbukti tidak sehat, tidak bisa diperbaiki dengan komunikasi, membuat Winny kehilangan diri sendiri

**Bentuk LIMIT yang sehat:** batasi waktu, batasi topik, batasi kanal (mis. hanya via email kerja), jangan langsung jawab di luar jam.

## Filter permintaan baru

Sebelum bilang "iya" pada permintaan apa pun, jawab 5 pertanyaan ini:

1. ☐ Apakah ini mendukung salah satu prioritas besar (Keluarga · Kesehatan · Dr. Winny · 4 Mesin Ekonomi · DI BALIK)?
2. ☐ Scope-nya jelas?
3. ☐ Kompensasi / timbal baliknya jelas dan layak?
4. ☐ Saya punya waktu **tanpa** mengorbankan non-negotiables (keluarga, tidur, riset)?
5. ☐ Kalau saya menolak, apakah saya akan lega?  *(kalau ✅ lega → itu jawabannya)*

**Skor:**
- 4–5 ✅ (dan no. 5 tidak dicentang) → **IYA**
- 2–3 ✅ → **NEGOSIASI** (perkecil scope / naikkan kompensasi)
- 0–1 ✅ → **TIDAK**, dengan sopan

> *Tidak semua masalah harus Winny selesaikan. Tidak semua konflik harus Winny jawab. Tidak semua orang harus Winny selamatkan.*
