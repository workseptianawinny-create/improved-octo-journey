**LIFE RESET → LIFE DESIGN → LEGACY**
Tema besar 2026–2030

## Ritme pemakaian

- **Mingguan** → `templates/weekly-review.md` + centang `action-plan/`

- **Kuartalan** → baca ulang `LIFE-DESIGN.md`, buat action plan kuartal berikutnya
- **Tahunan (10 September)** → `templates/annual-life-audit.md`
